  converge failures (`make install` on WSL and real hosts) at
  `TASK [conda : Verify Conda activation in a clean Fish login shell]`: `ansible.builtin.command` defaults to
  `expand_argument_vars: true`, causing Ansible's command module to run Python `os.path.expandvars()` on each `argv`
  element using `ansible-playbook`'s own parent environment after `shlex.split()` strips single quotes and before
  `env -i` executes. As a result, `$PATH` and `$CONDA_DEFAULT_ENV` in all three clean-shell Conda verification tasks

  child shell: Fish runs `string join : <single-colon-joined-parent-PATH>` (performing zero joins and exiting with
  `rc=1` and empty `stderr`), while Zsh and Bash silently assert against `ansible-playbook`'s parent `PATH` instead of
  the isolated shell `PATH`.
- **Exploration stance:** Focused exploit with deterministic task parameter fixes (`expand_argument_vars: false` and
  `string join : -- $PATH`) in `ansible/roles/conda/tasks/main.yml`, a static hygiene invariant across all role and
  playbook `ansible.builtin.command` tasks in `tests/test_toolchain.py`, and both static and hermetic `ansible-playbook`
  runtime verification in `tests/test_shell_hooks.py`.

## Risk Analysis

1. **Risk:** `ansible.builtin.command` defaults to `expand_argument_vars: true`, which invokes Python
   `os.path.expandvars()` on each `argv` element after `shlex.split()` removes single quotes and before `env -i`
   executes, corrupting any single-quoted shell script argument containing `$VAR`.
   - **Mitigation:** Set `expand_argument_vars: false` on all three clean-shell Conda verification tasks in
     `ansible/roles/conda/tasks/main.yml` and enforce `expand_argument_vars: false` via
     `test_ansible_static_task_hygiene()` in `tests/test_toolchain.py` whenever a command string outside `{{ ... }}`
     contains `$VAR`.
2. **Risk:** Subprocess unit tests that invoke `env -i <shell>` directly via Python `subprocess.run` bypass Ansible's
   `ansible.builtin.command` module wrapper and cannot catch Ansible module argument-processing bugs.
   - **Mitigation:** Add `test_ansible_conda_clean_env_shell_verification_playbook` in `tests/test_shell_hooks.py` to
     execute the actual tasks from `ansible/roles/conda/tasks/main.yml` via `ansible-playbook` with polluted parent
     `PATH` and `CONDA_DEFAULT_ENV` values.
