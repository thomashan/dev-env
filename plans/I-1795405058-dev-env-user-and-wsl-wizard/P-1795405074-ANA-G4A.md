## Risk Analysis

1. **Risk:** Tasks guarded by `when: not ansible_check_mode` (or roles omitted from CI `--check` runs, such as `conda`)
   are never evaluated by `ansible-playbook --syntax-check` or `make check-mode`, allowing undefined variables like
   `devenv_user` to cause runtime crashes during `make install`.
   - **Mitigation:** Define `devenv_user` in `ansible/group_vars/all.yml`, render all three Conda clean-shell
     verification `cmd` templates via `templar` in `tests/test_templating.py`, and audit all Jinja2 variable references
     across all role tasks and playbooks.

   `test_run_wizard_non_interactive` to observe `is_wsl() == True` from the host kernel/env and skip the apt GUI prompt
   unexpectedly.
   - **Mitigation:** Patch `scripts.devenv_wizard.is_wsl` to `False` in `test_wizard_gui_apps_prompts_brew_and_apt` and
     `test_run_wizard_non_interactive`, and test WSL behavior explicitly in `test_is_wsl_detection` and
     `test_wizard_skips_gui_apps_prompt_on_wsl`.
